Expressive Voices (Chatterbox) — Recording to Livestream

Mate records moods → argyre builds per-mood reference clips → tts-chatterbox renders each line with an emotion → cached in Postgres → existing Performer / Pulse / ffmpeg path to Twitch

Decision gates (cheapest first)

  • G1 bake-off: tuned Piper vs Kokoro vs Chatterbox
  • G2 accent test: 10 s of the mate's voice
  • G3 GB10 speed + memory beside vllm-agents
  • G4 pilot QC pass rate >= 90%
  • G5 mate approves, user judges stream fit
  • Tier 2 (only if G2 fails): fine-tune on 1-2 h

Risks

  • aarch64 / sm_121 PyTorch build (main unknown)
  • 13 GB free beside vLLM; OOM history
  • Zero-shot accent drift on AU vowels
  • Hallucinated syllables: ASR check + retry
  • Perth watermark in every clip
  • Convincing clone: consent scope must be explicit
